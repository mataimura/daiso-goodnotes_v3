# DAISO Ink → Goodnotes v0.3（無料iPhone Webアプリ）

ダイソー10.5インチ電子メモパッドの写真を、iPhoneのSafari内で筆跡解析し、Goodnotesで編集可能な `.goodnotes` ファイルに変換する無料のWebアプリです。Macでの変換・有料Pythonアプリ・外部APIは不要です。

## v0.3で追加した機能

- **忠実再現v5**: 白黒筆跡画像を基準に、Canvasで仮描画したストロークの線幅と位置を最適化
- **仕上がり線幅**: 「元画像に忠実」と「細め65%」を選択可能
- **従来の高速変換**: v0.2のアルゴリズムを残しており、枚数が多いときに切り替え可能
- **複数写真を1冊のGoodnotesへ**: v0.2で追加した最大20枚・順序変更・四隅補正を維持
- **変換中の進行状況**: 各ページの線幅探索・局所調整の進行を表示

## 現在GitHub Pagesでv0.2を使っている場合

1. `DAISO_Goodnotes_Batch_to_RasterFit_v03_Update.zip` を展開。
2. 既存のGitHubリポジトリのトップ（`index.html` がある場所）で、**Add file → Upload files** をクリック。
3. ZIPの中の5ファイルを上書きアップロードしてコミット。
   - `index.html`
   - `app.js`
   - `rasterfit.js`（新規）
   - `sw.js`
   - `manifest.webmanifest`
4. **`pipeline.js`, `goodnotes.js`, `vendor/`, アイコンは削除しないでください。**
5. 以前と同じGitHub Pages URLをiPhoneのSafariで開き直す。ホーム画面版で古い表示が残る場合は、Safari本体で同じURLを再読み込みし、ホーム画面アプリを終了して再起動する。サービスワーカー更新の都合で2回読み込みが必要になる場合もあります。
6. 下部に「バージョン 0.3（v5ラスター一致）」が表示されれば更新完了。

## 新規公開の場合

`DAISO_Goodnotes_RasterFit_v03_Full.zip` を展開し、**中身**をGitHub Pagesの公開リポジトリのルートに置いてください。`index.html` がルート直下にある状態にします。GitHub上で `Settings → Pages → Deploy from a branch → main / (root)` を設定。

## iPhoneでの使い方

1. Safariまたはホーム画面からアプリを開く。
2. 「写真を複数枚選ぶ」から1〜20枚選択。
3. 自動で囲った画面の枠を確認（ずれている場合だけ四隅修正）。
4. **ベクター化の方法**を「忠実再現v5」に設定し、線幅を「元画像に忠実」または「細め」にする。
5. 「まとめてGoodnotesに変換する」を押す。変換中はアプリを閉じない。
6. 仕上がりを確認して「Goodnotesへ共有」または「.goodnotesを保存」。

**大量の画像を一度にv5処理すると、iPhoneの発熱・速度低下・ブラウザのメモリ制限に当たる可能性があります。** 初回は1〜2枚でテストしてください。速さ重視なら「高速変換v0.2」に切り替えられます。

## アルゴリズムと制限

- `pipeline.js` が写真の画面領域検出・射影変換・青緑筆跡抽出・骨格のストローク化を実施。
- `rasterfit.js` が、出力した仮ストロークをCanvasに再描画。元の二値筆跡との画素F1を最大化するように **全体線幅 → 個々のストローク線幅/最大0.8pxの平行移動** を探索（2パス）。元のストロークの位相や筆順は復元しない。
- `goodnotes.js` は非公式のGoodnotesフォーマットを生成。Goodnotesの更新で互換性が変わる可能性がある。
- 表示する画像F1は**ブラウザ内部Canvas描画に対する近似**。Goodnotesのレンダリングエンジンの実際の忠実度ではない。F1は入力と同じ画像上での再構成誤差なので、汎化性能ではない。
- 端末内で処理。ページの写真や筆跡画像は通信・アップロードしない。GitHub Pagesへ公開するのはプログラムだけ。
- `index.html` とJavaScriptは無料静的ホスティングで配信できるが、Goodnotes自体の契約や利用権は別途必要。
